评鉴 / 空间

建筑

怎么进来，光落在哪，让人做什么。

核心脉络

建筑先问动线、光与尺度：人如何被引进来、看见什么、被鼓励做什么。好看常可落到重心、材质克制与错落；叙事空间还要警惕「舞台化真实」。

01

好看三律（民宅尺度）

上小下大降重心；外墙材质宜少且色调近；错落感往往比堆符号更像「有设计」。

02

风格是在回答问题

十种西方风格不是背名字，而是各自在回答「空间应该是什么样」。

03

尺度与路径造体验

逼仄门槛→开阔、垂直与迷宫、能动机关——路径设计比立面标签更能决定感受。

04

博物馆三问可迁移

看见了什么 / 看到了什么 / 谁被舞台化。一件展品讲完一个故事，胜过打卡清单。

05

城市更新看手段

秩序与微更新 vs 全拆；「创造光」比口号更能检验干预是否诚实。

典型失败

  • 把哥特等风格简化成「黑暗美学」贴纸。
  • 只看立面照片，不问动线与使用。
  • 以为自己看见了真实，其实看见的是灯光与省略排好的舞台。

边界

  • 电影布景魔法感与真实城市更新，评价轴不同。
  • 站内偏案例碎片，结构工程与规范层待补。

观察时先问

起步提问，用来对着脉络做现场核对。

  1. 人怎么进来，在里面被引向哪里。
  2. 光从哪落，结构能不能被看见。
  3. 它让人做什么、打算让人待多久，空间有没有配合这件事。
