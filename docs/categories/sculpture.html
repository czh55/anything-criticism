评鉴 / 图像与形体

雕像

转一圈之后，轮廓还在不在。

核心脉络

雕塑评鉴先绕圈：体量与空间、轮廓是否在多角度成立、材料与受力是否诚实。站内材料极薄，可先借「体积—主褶—收回」的造型逻辑与博物馆观看法起骨架。

01

当体积看，不当贴花看

大面先立住，再在受力处出主褶/主转折，最后收回小褶——衣服褶皱教学可迁移到形体判断。

02

多角度轮廓

只在一张照片好看不算；转圈后轮廓散掉，说明体量没有真正组织好。

03

材料与重力

支撑、悬挑、表面处理要说得通；违背材料脾气的「效果」往往假。

04

观看场合

展厅灯光与基座会舞台化对象；先问展方让你看见什么，再谈作品本身。

典型失败

  • 只从前视照片判断「神韵」。
  • 用题材感动代替形体是否成立。

边界

  • 公共纪念碑、架上小雕、装置艺术，评价轴不同。
  • video-notes / audio-workshop 几乎无雕塑专题，此页待重点补源。

观察时先问

起步提问，用来对着脉络做现场核对。

  1. 体量和它周围的空间是否匹配。
  2. 换一个角度看，轮廓还成不成立。
  3. 材料、受力的方式、近看的手工痕迹是否说得通。

材料厚度

脉络主要从 video-notes 与 audio-workshop 的总结中收束；厚薄决定后续补源优先级。
