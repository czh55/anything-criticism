评鉴 / 空间

装修

住进去之后，还烦不烦。

核心脉络

显大、显柔、显质感，靠灯光分层、色彩进退与焦点秩序协同。触觉往往先于视觉；全柔软会变成「窗帘城」，需要硬软对比留气口。

01

三层照明

基础 + 功能 + 氛围各有职分；无主灯≠满天筒灯。显色 Ra 高、色温可调，材质才站得住。

02

色彩进退

膨胀色靠前、收缩色退后；全屋米色会糊。家具与墙面位置反了，小空间更挤。

03

焦点秩序：点线面

一个主色点、一条导向线、一块中心面。背景只衬托，勿抢戏。

04

弱化边界优于硬扩

镜条延线、悬浮、开缝比硬拆更安全，但都有剂量：镜勿大面积对人、圆弧勿在小空间乱扩。

05

假色卡要识破

商业「莫兰迪色」常是提纯滤镜；真层次来自不均匀与关系，不是一整墙同色油漆。

典型失败

  • 无主灯理解成筒灯阵列，缺功能层与显色。
  • 满墙装饰、背光过亮，细节把墙面堆死。
  • 只追视觉清爽，忽略触感与住三个月后的烦。

边界

  • 样板间拍照好看，不等于动线与收纳成立。
  • 酒店东方美学的「可标准化体面」与住宅长期居住，标准剂量不同。

观察时先问

起步提问，用来对着脉络做现场核对。

  1. 动线顺不顺，常用的事要不要绕路。
  2. 光线和材料是否诚实，有没有用装饰盖住使用。
  3. 比例和收口经不经得住近看，住三个月后还烦不烦。
