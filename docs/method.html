评鉴 / 共同方法

同一件事

类别不同，评鉴时先走同五步。具体脉络写在各类别页；材料主要来自 video-notes 与 audio-workshop，再加日后的书与交流。

01

定对象

先说清评的是哪一层：材料、技艺、结构、意图，还是它在生活里造成的效果。层次混在一起，好坏就会变成口味争吵。

02

定场合

对谁、在什么条件下成立。一杯续命咖啡和一杯杯测、一间样板间和一套长住房，不是同一套合同。

03

找可重复的痕迹

审美常常是「找重点」和「分清」，不是堆形容词。对着可核查的痕迹：火候时机、明度秩序、运镜职分、反馈是否可读。

04

写出失败

废片、无印象菜、窗帘城、假色卡、散点隐喻、伪选择——差的典型样子往往比「很好」更能练判断。

05

留下边界

标准可以在绝大多数人那里重合，同时写清哪里不再适用。奖项、算法、稀缺身份，都不是痕迹本身。

跨类反复出现的尺子

从两个知识库里收束出的共用口令，写进各类别脉络时会再具体化。

  1. 先纠偏误解，再给标准——很多「高级」其实是名词用错。
  2. 可验证痕迹大于故事与标签：印象菜、光比、明度去色后是否仍清晰、规则是否教会人变聪明。
  3. 6:3:1 与主次秩序——色、空间、构图里反复出现的面积与重点分配。
  4. 系统/语法思维——原则咬合才像风格；单点技巧救不了空骨架。
  5. 失败样本练判断——废片识别、假莫兰迪、金奖通胀、表达竞赛。

一条记录长什么样

以后每则评鉴都按这四行写，方便跨类别对照。

  1. 对象：评的是哪一件具体事物。
  2. 场合：谁在用、在什么条件下。
  3. 判断：好在哪，差在哪，依据是哪条可重复的痕迹。
  4. 边界：这条判断不能外推到哪里。

材料怎么用

网络积累目前主要进两类仓库；各类别页「参考资料」列出具体标题与链接。

  • video-notes：咖啡、摄影、绘画、影视视听、家装、职场表达等主类总结最厚。
  • audio-workshop：饭菜、摄影审美、古典聆听、沟通场景、叙事细读等播客总结最厚。
  • 待补源：啤酒、游戏等站内几乎空白——脉络先立脚手架，不假装已有证据。
各类别页的「核心脉络」是可练习的骨架；「已记录」留给你之后写下的具体对象。
